# بوت تليجرام بهوية ثابتة (Kimi K3.1 Pro)

بوت ذكاء اصطناعي تحدد له هويته (اسم، شخصية، أسلوب، آراء...) ويلتزم فيها حرفياً.
لو حس إنه بيخالف الهوية أو يعترض عليها، ما يناقش — يأجل الموضوع لوقت لاحق ويكمل بنفس الشخصية.
ولا أحد يقدر يغيّر هويته من المحادثة غيرك أنت (المالك).

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env   # وعبّي القيم
python bot.py
```

القيم المطلوبة في `.env`:
- `TELEGRAM_BOT_TOKEN` من [@BotFather](https://t.me/BotFather)
- `MOONSHOT_API_KEY` من [platform.moonshot.ai](https://platform.moonshot.ai)
- `OWNER_ID` رقم حسابك في تليجرام (من [@userinfobot](https://t.me/userinfobot))
- `KIMI_MODEL` افتراضياً `kimi-k3.1-pro` (أو `kimi-k3.1-pro-highspeed` للأسرع)

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `/setpersona <النص>` | تحديد الهوية (للمالك). أو أرسل الهوية برسالة ورد عليها بالأمر |
| `/persona` | عرض الهوية الحالية (للمالك) |
| `/reset` | مسح ذاكرة المحادثة الحالية |
| `/resetall` | مسح ذاكرة كل المحادثات (للمالك) |

## مثال هوية

```
/setpersona اسمك "أبو فهد"، عمرك 55، من أهل نجد، تتكلم باللهجة النجدية فقط.
شخصيتك حكيمة وتحب تضرب الأمثال الشعبية. ردودك قصيرة.
تشجع الهلال ولا تقبل أي نقد عليه.
```

الهوية تنحفظ في `data/persona.json` وتبقى بعد إعادة التشغيل.
قواعد الالتزام بالهوية موجودة في `LOCK_RULES` داخل `bot.py` لو حبيت تعدلها.
